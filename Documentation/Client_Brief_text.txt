 CLIENT BRIEF
 Vari Smart Operations Platform
 Deep Learning Subject Project + Hackathon MVP
Track 2: Crowd, Mobility & Resource Management
1. Executive Summary
Vari Smart Operations Platform is a unified AI-enabled operational management system for Vari organizers. It monitors
crowd movement, predicts congestion, coordinates volunteers, monitors food/water resources, and raises sanitation alerts.
The system is designed as both a hackathon MVP and a Deep Learning course project. The main pipeline is: video/data
input → deep learning inference → analytics → prediction/risk → recommendation → real-time dashboard.

3. Project Vision
 SENSE → PREDICT → OPTIMIZE → ACT
 Sense: collect crowd, volunteer, resource and sanitation information.
 Predict: estimate crowd growth and operational risk using AI/ML.
 Optimize: recommend volunteers, routes and resource transfers.
 Act: present clear recommendations to the operator.
4. Main MVP Features
 Live Crowd Monitoring: crowd count, capacity, density and risk by zone.
 Crowd Risk Prediction: predict crowd level for the next 15–30 minutes.
 Live Vari Map: display zones, gates, volunteers, resources and alerts.
 Smart Volunteer Allocation: identify and recommend nearby available volunteers.
 Resource Monitoring: food/water levels and shortage detection.
 AI Recommendation Engine: recommend practical actions before situations become critical.
 Waste/Sanitation: monitor waste zones and create cleaning alerts.
5. Deep Learning Component
The Deep Learning course component will be centered on computer vision. A pretrained YOLO object-detection model
can detect people in crowd videos. OpenCV handles video processing.
 Video / CCTV → YOLO Person Detection → Person Count → Crowd Density → Risk → Alert /
Recommendation
 Object Detection: YOLO for person detection and counting.
 Computer Vision: OpenCV for frame processing and visualization.

6. Crowd Monitoring & Risk Logic
 density (%) = (current people / zone capacity) × 100
< 60% → SAFE
60–85% → MODERATE
85–100% → HIGH
> 100% → CRITICAL
These thresholds are prototype rules for the MVP and should be calibrated with real operational data before any real-world
deployment.
7. AI Decision Examples
 Gate 2 reaches 126% capacity → generate critical alert and recommend redirecting incoming crowd.
 Current crowd is 8,200 and predicted 15-minute crowd is 9,800 → warn the operator early.
 Critical zone requires 8 volunteers → find nearby available volunteers and recommend deployment.
 Water station falls below 25% → identify a nearby surplus station and recommend transfer.
 Sanitation zone exceeds 85% → create a cleaning task.

11. Data Strategy
Real event infrastructure may not be available during development, so the MVP uses a hybrid data strategy.
 Suitable crowd videos for demonstrating person detection.
 Simulated crowd, resource, volunteer and sanitation data.
 Historical/simulated time-series data for prediction experiments.
 A controlled simulation mode for the final hackathon demonstration.
Simulated values must be clearly identified as demo/simulation data and not presented as actual Vari measurements.
12. Volunteer Coordination
 Critical Zone → Required Volunteers → Filter Available → Calculate Distance → Select Suitable
Volunteers → Create Task
Volunteer records contain location, skills and availability. The MVP can use nearest-volunteer selection; more advanced
versions can use optimization algorithms.
13. Food & Water Optimization
 Shortage Station → Find Surplus Station → Calculate Distance → Recommend Transfer → Operator
Action
For the MVP, rule-based redistribution is sufficient. Future versions can use linear programming or vehicle-routing
optimization.

23. Features to Avoid in the 4–5 Day MVP
 Native mobile app
 Complex authentication/role system
 Real IoT infrastructure
 Real government/event-system integration
 Face recognition
 Large custom DL model from scratch
 Production-grade navigation
 Complex chatbot
 Large manual data-entry system
24. MVP Success Criteria
 Dashboard loads realistic simulation data.
 Live map displays operational zones and resources.
 YOLO detects/counts people in demonstration video.
 Crowd density and risk update correctly.
 Short-term prediction is visible.
 Critical events generate real-time alerts.
 Nearby volunteers can be recommended/assigned.
 Food/water shortage creates redistribution recommendation.
 Sanitation issue creates a task/alert.
 AI recommendation panel explains the suggested action.
 Frontend, backend, database and AI service communicate successfully.
 Complete demo runs reliably in under three minutes.
